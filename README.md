# Vega

Vega is a personal assistant that runs on its developer's own Windows PC. It
has exactly one user, who is also its developer.

Vega is a private, single-user project. It is not offered to the public and is
not available for others to use. It has no accounts, no server and no website
beyond these pages.

## Google Calendar

Vega asks Google for two read-only permissions: `calendar.events.readonly` and
`calendar.calendarlist.readonly`. It reads calendar events live, when the user
asks or when it builds a daily or weekly summary (a "brief") for the user. It
does not keep a copy of the calendar, and it cannot create, change or delete
anything in Google Calendar.
